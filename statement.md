Problem Statement

1. Project Title:
Personal Finance Tracker

2. Course:
CSE1021 – Introduction to Problem Solving and Programming (Python Essentials)

3. Problem Description:

Managing personal finances is a challenge for many students and individuals who lack access to
banking apps or internet-based finance tools. Most people rely on unreliable mental accounting, 
leading to unexpected overspending and poor savings habits, this project addresses that problem 
by providing a lightweight, offline, command-line personal finance management tool that requires no 
internet connection, no external libraries, and no prior setup — making it accessible to anyone with 
a Python installation.

4. Scope:

The scope of this project covers:
> Recording daily income and expense transactions with categories and notes
> Organizing transactions using a flexible, user-managed category system
> Setting and monitoring monthly spending budgets per category
> Generating insights through analytics (monthly summaries, trends, top spending categories)
> Exporting data as human-readable TXT reports or machine-readable CSV files
> Persisting data locally through JSON-based storage with backup support

Target Users:
> College students managing allowances and expenses
> Individuals tracking personal income and spending
> Anyone wanting an offline, private finance tracker

High-Level Features:
> Add / Edit / Delete transactions
> Filter and search transactions
> Manage income & expense categories
> Monthly analytics
> Spending trend comparison
> Per-category budget limits & alerts
> Report generation
> Backup and restore data
